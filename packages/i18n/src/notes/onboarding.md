# onboarding

- From `onboarding.tile.downloading`: The tile's second line at ~162px in a 4-up row: two or three words each. The explaining sentence is the setup dialog's (`onboarding.setup.*`).
- From `onboarding.tile.setupFailed`: Neutral: `failed` has two producers — a download that did not finish, and a turn the account could not complete.
- From `onboarding.setup.codex.connected.plan`: The connected body when codex named no plan: only which service answered.
- From `onboarding.setup.codex.planLine`: Codex's `planType`, capitalised by the mapping (`plus` -> Plus).
- From `onboarding.setup.codex.wontStart.title`: No period: a title, not a sentence.
- From `onboarding.found.group.people`: Group headings over where the person heard about Onlook. `people` holds word-of-mouth sources: a friend or colleague, a GitHub repository, an article. Name it as hearing from someone, not as "persons".
- From `onboarding.setup.codex.notSetUp.body`: Onlook installs a ChatGPT agent used only by Onlook; nothing else on the computer is affected.
