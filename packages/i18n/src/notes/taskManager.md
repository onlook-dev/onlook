# taskManager

- From `taskManager.title`: The Task Manager window, opened from Window → Task Manager…: what each Tab, Frame, agent and dev server is using. A desktop app's task manager; use the word the OS's own task manager uses.
- From `taskManager.total.app`: {app} is the product name. The total memory of the app's own processes, beside the memory of the programs it started.
- From `taskManager.total.children`: The total memory of the programs the app started: agents and dev servers.
- From `taskManager.devServer.port`: {port} is a port number.
- From `taskManager.process.pid`: {pid} is a process id number.
- From `taskManager.part.spareTab`: A Tab the app loads ahead of time so the next one opens fast.
- From `taskManager.frame.artifact`: An Artifact, a sketch on the Canvas, listed under its Tab's Frames in place of a page address. Use the product's word for Artifact.
