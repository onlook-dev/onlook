# code

- From `code.panel.label`: The left panel's code view. It is the panel's accessible name while that view is showing, in place of `sidebar.label`.
- From `code.panel.empty`: Says what the view is showing. It names no control.
- From `code.panel.unsavedDot`: On the dot that replaces a tab's ✕ until the tab is hovered.
- From `code.refused.noProject`: Why a file couldn't be opened or read: one sentence per reason.
- From `code.save.unsaved`: The save bar, and the five reasons a save can be refused.
- From `code.clash.agent`: The banner shown when the file changed on disk while the designer was editing it. It says what Onlook couldn't reconcile, never what either side wrote.
- From `code.tint.declined`: The Files view. Three different causes share one sentence, because the designer can do the same thing about all three.
