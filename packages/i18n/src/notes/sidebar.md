# sidebar

- From `sidebar.label`: The left panel: the project name and the Designs list.
- From `sidebar.text.untitled`: Shown for a text item only while it is still empty; an image with no file name uses `canvas.image.pastedName`.
- From `sidebar.frame.renameLabel`: The accessible name of the inline rename field.
- From `sidebar.section.show`: The arrow on a Section row in the Designs list.
- From `sidebar.empty.title`: The empty Designs list: one quiet line under the placeholder rows.
- From `sidebar.pages`: The Pages section above the Designs list.
- From `sidebar.pages.newName`: The name a new page gets: the page count plus one. Two pages may share a name.
- From `sidebar.pages.dividerLabel`: A divider has no name to read out, so the row announces what it is.
- From `sidebar.pages.delete.title`: Asked only when the page holds something; an empty page is deleted without asking.
