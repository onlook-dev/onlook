# projects

- From `projects.badge.beta`: The projects view. The card's `⋯` button has no visible text, so `projects.card.menu` is read by screen readers only. The chip beside the wordmark marks a beta build, not a version number.
- From `projects.workspace.menu`: Accessible names only: the Workspaces header's add button and a workspace row's `⋯` have no visible text.
- From `projects.section.archivedProjects`: The faded section below a workspace's grid, where archived projects stay instead of disappearing.
- From `projects.menu.rename`: The two context menus. `newProject` above is reused as the workspace menu's first item, with the same words as the header button.
- From `projects.rename.field`: The inline rename fields the two Rename items open. Accessible names only.
- From `projects.time.justNow`: The card's subtitle: how long since the project was last opened.
- From `projects.card.missing`: A project whose folder is gone.
- From `projects.discover.title`: The card at the bottom of the sidebar. It also reaches people who set Onlook up long ago, so it refers to no recent step.
- From `projects.remove.confirm.message`: Built from parts, in this order: the folder sentence, the uncommitted-changes line, then one sentence on what is kept.
- From `projects.remove.workspace.confirm.folder`: Built from parts, in this order: the count sentence, the uncommitted-changes line, then one sentence on what is kept.
- From `projects.newProject.group`: The faded section for project folders on disk that Onlook has no record of, and the menu that opens the folder picker.
- From `projects.discover.body`: One plain sentence: a star on GitHub helps more designers find Onlook. `projects.discover.star` is the button that gives the star.
