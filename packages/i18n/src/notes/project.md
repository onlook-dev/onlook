# project

- From `project.create.planning`: Project setup progress in Project Chat, one line per stage. `{repo}` is the folder's name, shown as a chip; put it where the sentence needs it, not at the end by default. The failed lines name the stage; the `next` lines say what Retry does for it.
- `project.create.copy.*` are the copy failures, each ending in the one thing the person does next. A line that says to choose the folder again is shown beside the `project.create.chooseFolder` button, which opens the folder picker; a line that says to click Retry is shown beside `project.create.retry`. `project.create.details.show` and `.hide` label the control that opens Git's own words below the buttons.
