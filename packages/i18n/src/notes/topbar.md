# topbar

- From `topbar.folder`: The bar along the top of the window. These are accessible names and tooltips; keep each one different from every other control on screen.
- From `topbar.rail.left.hide`: The panel toggles name the action, not the state: a control labelled with what it currently is reads as a status and gets pressed by mistake.
- From `topbar.update.checking`: The update indicator in the top bar. Only these states show anything; when nothing is happening it shows nothing.
