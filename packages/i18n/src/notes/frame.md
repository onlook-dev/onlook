# frame

- From `frame.label`: A Frame on the canvas: its header, its status and its menu.
- From `frame.health.failed.https`: The page's server answered, but loading the page failed.
- From `frame.health.loading.label`: The first frame's loading state, cleared when the page finishes loading.
- From `frame.kind.htmlArtifact`: Names the kind of thing a frame shows, beside its size: here, a static HTML Artifact.
- From `frame.size.mobile`: The device-size presets. Only the names are translated; the sizes themselves are fixed.
- From `frame.url.openInNewFrame`: In the address field: opens the address in a new frame beside this one instead of changing this frame. Enter keeps its usual meaning.
- From `frame.name.copy`: The name given to a duplicated frame. The user sees and can edit it.
