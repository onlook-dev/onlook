Format:
- Japanese ends on the verb: move a placeholder before it, and never leave a name stranded after the verb.
- Put one half-width space between Japanese text and Latin letters or digits (Google でサインイン, 2 分). No space next to Japanese punctuation.
- A placeholder holding a name, a number or Latin text is spaced like Latin ({count} 個, {repo} を起動). One holding Japanese words takes no spaces ({privacyPolicy}と{termsOfService}に同意).
- Use full-width punctuation in Japanese text: 。、「」？！（）： — never half-width ? ! ( ) : beside Japanese. Quote a label the user must find with 「」.
- Finder stays Finder, as macOS shows it in Japanese.

Voice:
- Buttons, menu items and labels: plain form, noun or verb stem (保存, キャンセル, 次へ, アカウントを削除する). Never はい、…します on a button.
- Sentences and messages: polite です/ます form ("can help" → できます).
- Don't open a sentence with あなたは or attach あなたの; Japanese drops the subject. Use 自分の only where the contrast matters (自分のコード). A sentence that would read bare names its subject (このリポジトリはすでに…, このフォルダーには…).
- Asking the person to pick one of several things in a sentence: 選んでください. 選択 stays for selecting on the canvas and for labels.
- Everyday words: 待つ, not 待機; もう一度 over 再 for a retry the user starts; 次へ for moving through steps, not 続行.

Words:
- Katakana loanwords keep the final long vowel: ブラウザー, フォルダー, コンピューター, サーバー, ユーザー, プロバイダー, エディター, メンバー.
- Product terms: Workspace → ワークスペース; Project → プロジェクト; Canvas → キャンバス; Page → ページ; Frame (also "browser") → フレーム; Artifact → アーティファクト (everywhere, captions included; never 成果物); Object → オブジェクト; agent / Onlook Agent → エージェント; chat / conversation → チャット; chat panel → チャットパネル; Sidebar → サイドバー; Tab → タブ; branch → ブランチ; commit → コミット; pull request → プルリクエスト; repository → リポジトリ; sign in → サインイン; dev server → 開発サーバー; Tips → ヒント, never コツ.
- The Designs list → デザイン一覧; the Design mode tab → デザイン. Never use plain デザイン for the list.
- Plan mode → プランモード, never plain プラン, which reads as a pricing plan (Max プラン). Accept edits mode → 編集を自動承認.
- Starting and stopping the user's app → 起動 / 停止. An interrupted agent turn → 中断しました, never 停止.
- Set up (an agent, a project) → セットアップ, never 設定, which means settings.
- Pan the canvas → キャンバスを移動; the hand tool → 移動.
- Reveal in Finder → Finder に表示.
- Refresh a list → 一覧を更新.
- Check again → もう一度確認, never 再確認. Retry → 再試行 on a button. In a sentence, asking the person to try again is もう一度お試しください, or しばらくしてからもう一度お試しください where waiting is what helps; never 再試行してください, and never the action's own verb (もう一度クローンしてください). A sentence that points at the Retry button quotes its label: 「再試行」をクリック.
- Wait for approval → 承認を待つ. Waiting for the user's answer → 回答待ち.
- Switch to another agent or model → ChatGPT に切り替える (not …を使用, not 代わりに…). "… instead" on a button: フォルダーから追加, ブラウザーでサインイン; drop 代わりに.
- Coming soon (a feature or provider) → 対応予定.
- A connection that dropped → 切れました, not 切断されました.
- Access to GitHub or a repository → アクセス権, the same word throughout a dialog; 権限 is for the agent's permission modes.
- Remove a project → 削除, made clear by the sentence that only Onlook's copy goes.
