Write Simplified Chinese as used in mainland China, and drop pronouns and connectives Chinese does not need.

Format:
- Put one half-width space between Chinese text and Latin letters or digits (使用 Google 登录, 2 分钟). No space next to Chinese punctuation.
- A placeholder holding a name, a number or Latin text is spaced like Latin ({count} 个, 启动 {repo}). One holding Chinese words takes no spaces (同意{privacyPolicy}和{termsOfService}).
- Use full-width punctuation in Chinese text: ，。、？！：；（） — never half-width , . ? ! : ; ( ) beside Chinese. Quote a label the user must find with “”.
- Write the ellipsis "…", never "……".
- Finder is 访达, as macOS shows it in Chinese.

Voice:
- Buttons, menu items and labels: a verb or a noun, no 请 and no full stop (保存, 取消, 下一步, 删除账户).
- Sentences and messages: "can help" → 可以. Address the user as 你, never 您, and leave it out wherever the sentence reads without it; write 你的 only where the contrast matters (你自己的代码).
- Everyday words: 等待, not 待机; 再试一次 in a sentence the user acts on.

Words:
- Product terms: Workspace → 工作区; Project → 项目; Canvas → 画布; Page → 页面; Frame (also "browser") → 画框; Artifact → 工件; Object → 对象; agent / Onlook Agent → 智能体 / Onlook 智能体; chat / conversation → 对话; chat panel → 对话面板; Sidebar → 侧边栏; Tab → 标签页; branch → 分支; commit → 提交; pull request → 拉取请求; repository → 仓库; sign in → 登录; sign out → 退出登录; dev server → 开发服务器; Settings → 设置.
- A page of the user's own site is a 页面 too; a Frame is never 页面 or 框架.
- The Designs list → 设计列表; the Design mode tab → 设计, and Preview → 预览. Never use plain 设计 for the list.
- Plan mode → 计划模式. A pricing plan is 套餐 (Max 套餐), never 计划. Accept edits mode → 自动接受编辑.
- Starting and stopping the user's app → 启动 / 停止. An interrupted agent turn → 已中断, never 已停止.
- Set up (an agent, a project) → 配置 or 准备, never 设置, which is Settings. Install → 安装.
- Pan the canvas → 平移画布; the hand tool → 平移.
- Reveal in Finder → 在访达中显示.
- Refresh a list → 刷新列表.
- Check again → 重新检查. Retry → 重试 on a button, 请重试 in a sentence.
- Wait for approval → 等待批准. Waiting for the user's answer → 等待回复.
- Switch to another agent or model → 切换到 ChatGPT (not 使用…, not 改用…代替). "… instead" on a button: 从文件夹添加, 在浏览器中登录; drop 改为 and 代替.
- Coming soon (a feature or provider) → 即将推出.
- Remove a project → 移除. Delete (an Artifact, an account) → 删除.
- Undo → 撤销; Redo → 重做; Copy → 拷贝 as macOS menus say it, 复制 for duplicating a project or an Object.
