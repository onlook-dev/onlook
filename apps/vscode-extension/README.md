# Onlook - Local VSCode Extension

Local development bridge for Onlook, connecting your VSCode/Cursor to the Onlook web editor.

## Features

- WebSocket server bridging web editor to local filesystem
- Dev server management (Next.js)
- File operations (read, write, watch)
- Terminal integration

## Commands

- **Onlook: Create Local Project** - Create a new local project
- **Onlook: Open in Browser** - Open the Onlook web editor in your browser
- **Onlook: Show Connection Status** - Show WebSocket server status
